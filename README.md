# LCB-Extraction
Limbus Company extraction simulator.
/Currently in Beta. Soon to have an index feature and additions to the roster.


# GUIDE

Simple and easy, click "Extract" to get a random ID on the rarity levels of 0, 00 and 000. The latter being the best and the former being the worst. Currently it simply picks an image from a folder based on the rarity but soon it will be much, much more detailed.
